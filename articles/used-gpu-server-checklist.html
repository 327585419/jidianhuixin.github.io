买二手 GPU 服务器怎么验货？一份 30 项现场检查清单

发布：2026-09-24 分类：行情与价格 阅读约 9 分钟

二手 GPU 服务器不是普通二手电脑，它更像一台“已经跑过几年重活的工程设备”。验货的核心逻辑只有一句话：先看不可逆的，再看可修复的。外壳划痕、缺导轨、少螺丝都能补；显存颗粒老化、ECC 错误累积、主板烧蚀、NVLink 链路损坏，基本等于判死刑或大修。所以现场顺序应该是：外观与配置核对 → 通电看识别 → 查错误计数 → 显存与链路测试 → 压力与温度 → 电源/背板/风扇 → 交易留证。下面这份 30 项清单，按这个顺序展开。

一、先看“不可逆”的：外观、配置与身份核对

  1. 核对型号与卡型：V100 要分清 PCIe 还是 SXM2，A100 要分清 40GB 还是 80GB、SXM4 还是 PCIe。两者带宽、功耗、互联能力完全不同，不能只听卖家说“A100”。
  2. 看 GPU 序列号与机身标签是否一致：用 nvidia-smi -q 里的 Serial 与机箱标签、采购单据比对，防止“换卡”。
  3. 查主板与背板烧蚀痕迹：重点看 PCIe 插槽、SXM 基板、供电接口附近有无发黄、发黑、焊油残留。
  4. 看被动散热鳍片是否变形：V100 全系被动散热，鳍片压伤会直接影响风道效率。
  5. 确认电源冗余：服务器应配双电或四电，缺一路还能降功率跑；单电机器压测时容易掉电。
  6. 检查背板与盘位：背板型号、SAS/SATA/NVMe 支持、盘位数量要跟描述一致，缺背板等于整机残废。
  7. RAID 卡与缓存电池：有 RAID 卡要看型号、缓存大小、电池是否鼓包；无电池的写缓存策略要确认。
  8. 风扇与导轨：原装风扇数量、转速是否可调；导轨缺失虽可后配，但说明上架环境可能粗暴。
  9. 看机箱螺丝与防拆贴：螺丝齐全、防拆贴完整说明没被反复拆修；缺失则要追问原因。

二、性能与健康：nvidia-smi、ECC 与显存测试

  1. nvidia-smi 看识别数量与拓扑：确认所有卡都被识别，nvidia-smi topo -m 看 NVLink 是否成对出现。SXM2 V100 应显示 NVLink，PCIe 版没有。
  2. 看 Persistence Mode 与驱动/CUDA 版本：驱动太老会影响新框架，CUDA 版本要跟你的 PyTorch/vLLM 组合匹配。
  3. 读 ECC 错误：nvidia-smi -q | grep -i ecc 重点看 Volatile 与 Aggregate 的 Corrected/Uncorrected。有 Uncorrected 或持续增长的 Corrected，直接放弃。
  4. 看 Retired Pages：显存有不可恢复页会被退休，数量不为 0 说明颗粒已老化。
  5. 看温度与功耗墙：nvidia-smi -q -d POWER,TEMPERATURE，确认当前功耗上限和温度阈值是否被改过。
  6. 显存测试：现场跑 cuda-memtest 或厂商诊断工具，至少覆盖全部显存；V100 32GB 要跑满 32GB，A100 80GB 要跑满 80GB。
  7. NVLink 带宽测试：SXM2 机器用 nvbandwidth 或 NCCL 小测试，确认 6 链路约 300GB/s 双向聚合量级；异常低说明链路或基板有问题。
  8. PCIe 链路宽度与速率：nvidia-smi -q | grep -i link 确认 x16 与 Gen3/Gen4 符合预期，降速可能是插槽或转接板问题。
  9. 注意 V100 软件兼容性：sm_70 在新版 PyTorch/vLLM 中官方支持逐步淡化，部署前必须实测你的版本组合，别等买完才发现跑不起来。
  10. A100 要写清对比口径：SXM4 与 PCIe 的带宽、功耗不同，谈性能时必须说明是哪种形态。
  11. RTX 4090 别当服务器卡用：24GB 显存、无 NVLink、无 ECC、非服务器风道，多卡并行和长期稳定性跟 V100/A100 不是一个赛道。

三、压力与稳定性：跑多久、看什么

  1. 短压 10 分钟：先跑 gpu-burn 或矩阵乘，看是否立刻报错、掉卡。
  2. 长压 30~60 分钟：观察温度是否持续爬升、是否触发降频。二手卡建议至少 30 分钟，整机交付建议 1 小时。
  3. 看降频原因：nvidia-smi -q -d PERFORMANCE 里查 Clocks Throttle Reasons，区分温度墙、功耗墙、还是硬件慢速。
  4. 看风扇与进风温度：被动卡依赖机箱风道，进风温度高会直接撞温度墙；现场要摸出风口、看转速。
  5. 看电源功率余量：8 卡 V100 SXM2 整机功耗很高，电源额定功率要留足余量，压测时看是否掉电重启。
  6. 看日志有无 Xid 错误：dmesg | grep -i xid，出现 Xid 说明驱动层已记录硬件异常，不能忽略。

四、常见话术识别与交易保障

  1. “成色 99 新”怎么判断：看成色不如看 ECC 计数、退休页、螺丝与防拆贴。外观再新，ECC 有 Uncorrected 也不能要。
  2. “一直自用、没跑过重活”：要求看 nvidia-smi -q 的累计错误与温度历史，跑过矿或长期训练的卡，散热鳍片和供电口会有痕迹。
  3. 价格区间要有时效声明：截至 2026 年，二手 V100 32G SXM2 拆机卡约 3000~6000 元，V100 32G PCIe 约 6000~9000 元，V100 32G 整机九成新约 1.8 万~2.3 万元；云上 V100 实例月付约 3800 元级，云租用约 0.16 美元/GPU/小时起。以上仅供参考，以当日货源为准。
  4. 交易留证与售后：面交要现场跑完上述测试再付款；外地走顺丰保价，录制开箱与上电视频；合同写清保修期、ECC 异常是否包换、是否含系统与 CUDA 环境安装。成都本地可面交/上门，外地可保价发货，售后条款要落到文字。

结论/建议：二手 GPU 服务器验货，顺序比工具更重要——先排除不可逆的硬件损伤，再谈性能和价格。V100 适合预算有限、能接受 sm_70 兼容性风险的场景；A100 更适合需要 BF16、MIG 和更高带宽的生产环境；RTX 4090 则是单卡性价比路线，别硬套服务器形态。把 ECC、显存、NVLink、温度和电源这五项跑透，基本能避开九成坑。
